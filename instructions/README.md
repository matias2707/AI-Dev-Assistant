# Instructions

Reglas adicionales y contexto específico para Claude Code que complementan `CLAUDE.md`.

## Qué va aquí

Archivos markdown con reglas o restricciones que aplican a un área concreta del proyecto. No repetir lo que ya está en `CLAUDE.md`; esto es para casos específicos o excepciones.

Ejemplos de archivos que podrían vivir aquí:
- `auth.md` — reglas para implementar autenticación si se agrega en el futuro
- `migrations.md` — cómo manejar migraciones de base de datos con Alembic
- `error-handling.md` — convención para manejo de errores HTTP

## Cómo escribirlos

- Cortos y directos. Una regla por párrafo.
- Si aplica solo a una capa, indicarlo explícitamente.
- Nombrar el archivo por el área que cubre.
- No duplicar lo que ya está en `CLAUDE.md`.
